# Deploying the sync worker

You need Docker and a Langfuse project. The worker reads `LANGFUSE_SECRET_KEY` from the environment — never commit it.

1. Copy `.env.example` to `.env` and fill in the keys.
2. Run `docker compose -f docker-compose.sync-worker.yml up -d`.
3. Check health with `python3 core/telemetry/python/agent_sync.py status`.

The first push uploads every prompt file. Later pushes send only files whose SHA changed, so a quiet week costs a handful of API calls. If you rename a prompt, the old Langfuse label stays behind; delete it in the dashboard to avoid duplicates.
