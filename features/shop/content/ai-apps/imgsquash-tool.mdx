## imgsquash.com

### Developer Kit for Advanced Image Optimization Apps

With this product, any developer can build a fully functioning image optimization app that handles conversion, compression, and AI-powered upscaling in-browser—reducing file sizes while boosting quality, perfect for web performance gains.

### Key Features

- **Format Conversion & Compression**: Support for AVIF, WebP, PNG, JPEG XL—lossless and lossy modes
- **AI Upscaling**: Integrate Real-ESRGAN for enhancing low-res images
- **Configurable Quality**: Balance size and visuals with adjustable settings
- **Bulk Processing**: Handle multiple files at once
- **Size Reduction**: Achieve major shrinks without quality hits
- **Privacy First**: All processing client-side, no uploads
- **Instant Outputs**: Quick previews and downloads

### Technical Specifications

- **Formats Supported**: AVIF (superior compression, transparency), WebP (efficient, lossy/lossless), PNG (lossless, transparency), JPEG XL (advanced features), JPEG (universal)
- **Engine**: Browser APIs + Real-ESRGAN AI
- **No Installation**: Pure browser runtime
- **Limitations**: AVIF/WebP may need browser checks; heavier compression demands more power
