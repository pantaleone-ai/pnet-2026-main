- **Platform Support**: Converts exports from multiple CMS
- **SEO Optimization**: Preserves rankings with clean MDX
- **Local Processing**: Runs in-browser for privacy
- **Performance Gains**: Optimizes for Next.js SSR/SSG

- **Output Format**: MDX for headless compatibility
- **Privacy**: Local execution, no data upload
