## MigrateCMS Tool

### Developer Kit for CMS Migration Apps

With this product, any developer can build a fully functioning content migration app that converts exports from WordPress, Shopify, Wix, Squarespace, and Webflow to SEO-optimized MDX for Next.js—preserving rankings, stripping bloat, and boosting performance, all in-browser.

### Key Features

- **Platform Support**: Handles WordPress (XML), Shopify (CSV), Wix/Squarespace/Webflow (HTML feeds), RSS
- **SEO Optimization**: Preserves slugs, dates, tags, meta descriptions; enables 301 redirects and sitemap generation
- **Data Cleanup**: Strips Liquid tags, shortcodes, messy HTML for clean output
- **Local Processing**: Client-side execution for privacy—no servers or data uploads
- **Performance Gains**: Optimizes for Next.js SSR/SSG, Core Web Vitals improvements (3x faster loads)
- **Headless Integration**: MDX output with frontmatter for easy pairing with Sanity.io, Strapi, Contentful
- **Migration Checklist**: Built-in guides for pre-audit, metadata transfer, redirect setup

### Technical Specifications

- **Input Formats**: XML (WordPress), CSV (Shopify), HTML (Wix/Squarespace/Webflow), RSS
- **Output Format**: MDX with frontmatter (title, date, slug, tags, meta)
- **Framework/Engine**: Next.js 16, React 19, client-side JavaScript parsing
- **Compatibility**: Works with any MDX-compatible static site generators
- **Limitations**: Requires manual export from source CMS; no dynamic DB handling; post-migration redirects manual

### Ideal For

- Developers crafting migration tools for Next.js upgrades
- Builders integrating into headless CMS workflows
- Devs enhancing e-commerce or site rebuild pipelines
- Any dev embedding SEO-preserving content transfers

### What's Included

- Browser-based upload and parsing interface code
- Normalization and cleanup logic
