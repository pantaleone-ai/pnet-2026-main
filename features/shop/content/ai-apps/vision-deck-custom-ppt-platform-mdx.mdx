## Vision Deck

### Source Code for Custom Presentation Platform

Buyer receives complete source code to build and deploy a fully custom presentation & communications platform. Replace bloated slide tools with clean, code-first MDX slides, Framer Motion animations, typed frontmatter, automatic ordering, validation, and JSON API for AI agents or dynamic content.

### Key Features

- MDX slides with six typed types (Hero, Timeline, Stats, Quote, Messages, Terminal)
- Filename-driven ordering & validation
- Built-in Framer Motion transitions
- Prism syntax highlighting
- Real-time JSON API endpoint
- Extensible MDX components

### Technical Specifications

- Next.js 16 App Router
- React 19 + Tailwind CSS 4
- MDX + next-mdx-remote
- TypeScript strict typing

- Teams creating AI-powered comms tools
- Companies replacing PowerPoint/Google Slides workflows
