## Next.js AI Starter App

### AI SaaS boilerplate

Fork and launch an AI SaaS: Next.js 15, auth, themes, dashboards. Skip the wiring weekend.

### Key Features

- **Modern Stack**: Next.js 15 App Router with Server Components throughout
- **Type Safety Locked**: Strict TypeScript everywhere—no loose ends
- **UI Foundation**: shadcn/ui + Tailwind v4—customizable, copy-paste, zero bloat
- **Runtime Theming**: Dark/light modes, multi-scheme switching via next-themes
- **Production Patterns**: Dynamic dashboards, pricing tables, real-time chat UIs ready to hook AI streams
- **Responsive Core**: Mobile-first layouts that hold up on any device

### Technical Specifications

- **Framework**: Next.js 15 (App Router + Server Components)
- **Language**: TypeScript (strict mode enforced)
- **Styling**: Tailwind CSS v4 + shadcn/ui primitives
- **Theming**: next-themes for dark/light mode + custom schemes
- **Architecture**: Server-first where it counts, client hydration minimal
- **Extensibility**: Plug in any AI provider (OpenAI, Anthropic, Grok, etc.) via API routes or server actions

### Ideal For

- Builders shipping AI chatbots, assistants, analyzers, generators
- Devs tired of reinventing auth/UI boilerplate every project
- Teams needing scalable, maintainable SaaS foundations
- Anyone who values execution speed over starting from create-next-app

### What's Included

- Project structure with routing and components
- Pre-wired shadcn/ui + custom components (dashboards, forms, tables, chat)
- Complete theme system (dark/light + runtime switches)
- Responsive layout templates (landing, admin, pricing, etc.)
- Setup docs + extension guides
- Example patterns for AI API integrations (streaming, error handling)

### Get Started Fast

Fork this, wire your AI endpoint in one file, deploy to Vercel. No more crumbling setups from outdated starters. Build the real thing—fast, clean, yours.
