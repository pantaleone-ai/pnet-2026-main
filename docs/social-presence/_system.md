# Social Presence System (reusable template)

Reusable checklist distilled from the 47-section playbook. Per-app audits live in
`<app>.audit.md`. No secrets in this folder. Never commit tokens.

## 1. Audit (read-only, no invention)

- Project: what / who-for / differentiator / benefit / model / conversion
- Brand: logo, colors, type, imagery, voice, positioning (from site + repo)
- Website: homepage, product, pricing, blog, about, contact, OG tags, social links
- Existing social: list each platform account or mark unknown. Never invent followers.

## 2. Objective + audience

- 1 primary objective, 1-3 secondary. Map DISCOVERY → RETENTION.
- Primary + secondary audiences from evidence only. Unknown = unknown.

## 3. Positioning

`[Product] helps [audience] [outcome] without [common problem].`
Ban generic: future of, revolutionizing, unlock, game-changing, cutting-edge.

## 4. Platform strategy

Classify per app: Primary / Secondary / Experimental / Not recommended with reason.
Default visual-commerce apps: Primary Pinterest/Instagram/Facebook.

## 5. Profile drafts (do not apply without owner confirm)

Name, handle, image, cover, bio (WHAT+WHO+BENEFIT), about, CTA → real URL,
pinned orientation post (WHAT→WHO→WHY→NEXT, no "Welcome to our page!").

## 6. Content system

- 4-7 pillars, 3-6 series, formats native per platform (no mechanical cross-post).
- Mix 60-80% useful / 20-40% product. Hooks must reflect real product.
- Voice = site voice. Human standard: would a real insider plausibly write this?
- Hashtags 0-5 specific. Deep links + consistent UTM:
  `utm_source=<platform>&utm_medium=organic_social&utm_campaign=<campaign>`.

## 7. Ops

- Cadence sustainable (often 3-5/week). Engagement as participant, no bait.
- Automation only for scheduling/analytics/UTM/drafts. Never auto-reply complaints.
- QC before publish: accuracy, links, spelling, voice, CTA, mobile, rights, tracking.

## 8. Measure

Discovery (reach, profile visits) / Engagement / Traffic / Conversion / Retention.
One-variable experiments, document results, no decisions from single post.

## 9. Output per app (sections A-L)

Executive summary, current state, ranked findings, platform strategy, profile copy,
visual specs, content strategy, 30-day calendar, 90-day plan, KPIs, funnel,
Immediate/Next/Later/Optional implementation plan.
